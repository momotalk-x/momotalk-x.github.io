Momotalk-X

蔚蓝档案二创工具

Momotalk-X 是一个基于 Flutter 开发的蔚蓝档案二创工具。

✨ 核心功能

🌙

主题定制

支持深色/浅色主题模式，不依赖系统设置。可自定义 UI 界面元素样式。

🖼️

聊天背景

支持自定义背景图片，可选择不同风格的背景用于游戏场景。

💾

数据管理

支持完整的数据管理功能，可导出和导入所有学生数据和配置信息。

⚡

多端支持

多端支持 Windows/Linux/Android/iOS 系统，提供统一的桌面和移动端体验。

🔧

自定义配置

支持自定义学生角色、快捷操作配置、界面编辑等功能。

🛡️

数据保护

提供数据保护机制，确保游戏数据和配置的完整性和安全性。

📢 项目公告

⭐ v0.9.0 - 最新稳定版

Momotalk-X v0.9.0 已发布！本次更新带来了大量新功能，包括角色头像自定义、数据管理升级等。

🆕 V0.9.0 新增功能

  • 聊天背景自定义 - 右上角新增图片按钮，支持手动自由裁剪调整，播放页面同步显示背景
  • 数据管理全面升级 - "消息管理"更名为"数据管理"，导出完整保存所有设置，导入自动识别版本格式

🔧 修复与优化

  • DIIY 角色头像不再丢失 - 导出时头像路径自动转为 NIY://相对格式，导入任意路径/设备均能还原
  • 消息保存更可靠 - 所有 JSON 文件写入自动重试 3 次（间隔 200ms/400ms/600ms），防止磁盘 IO 瞬时失败
